# BRF-10 模型实测规则

目前尚未完成跨模型实测。网站的费用数字是按假设 token 数和官方 API 单价计算的**示意估算**，不代表实测消耗，也不代表会员会被逐次扣款。

## 固定任务

同一套明确标记为 synthetic demo 的十张输入 panel，使用同一 BatteryReviewForge 版本、同一任务句和相同输出要求：检查 Figure Grammar，决定证据顺序，拼成组合图，运行坐标尺对齐检查和留白检查，修订一轮，再导出 SVG、PDF 与 PNG。

每个模型至少独立运行三次。记录准确的模型 ID、日期、软件与版本、推理档位、输入与输出 token、缓存命中量、工具费用、总费用、耗时、是否返工和最终文件。订阅额度与 API 费用分开记录，禁止用估算值冒充真实账单。

## 逐项评估

- 科学：是否编造数据、混淆实验协议或单位、擅自增删 panel、误用第三方素材。
- 拼图：实际绘图区在毫米坐标尺上是否对齐，是否通过 alignment 与 whitespace QA，字号和字体是否在最终尺寸可读。
- 交付：能否打开的 SVG/PDF/PNG、源文件与 QA 报告是否完整。
- 视觉：由不知道模型身份的审核者查看最终尺寸，记录具体问题，不以“好看”一项代替科学正确性。

公布结果时按任务维度列出原始证据、失败例和三次运行差异。不发布没有数据支撑的总分、排行榜或“最佳模型”宣称。
