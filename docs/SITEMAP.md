# 网站地图

普通用户从 [首页](index.html) 开始，不需要先打开 GitHub。

| 页面 | 用户来这里做什么 | 下一步 |
| --- | --- | --- |
| [首页](index.html) | 三秒看懂产品，并选择开始或看样图 | [开始使用](start.html)、[样图库](gallery.html) |
| [开始使用](start.html) | 选已有软件、按系统安装、用演示文件试图 | `?task=full`、`?task=ce`、`?task=assembly` |
| [功能](features.html) | 判断手里的材料适合画图、拼图还是综述 | 开始使用或样图库 |
| [样图库](gallery.html) | 放大查看示例，下载输入数据、SVG、PDF | 开始使用、[学习](learn.html) |
| [学习](learn.html) | 看兼容状态、CE 区别和 SVG 微调 | [兼容性详解](COMPATIBILITY.md) |
| [简明指南](guide.html) | 按实验数据、现成图片、综述三类任务起步 | 对应任务的开始使用页 |
| [数据与责任说明](disclaimer.html) | 了解数据归属、水印、演示图和投稿前复核 | 返回开始使用 |
| [社区](community.html) | 查看版本、贡献者和维护情况 | [参与贡献](contribute.html)、[路线图](roadmap.html) |
| [参与贡献](contribute.html) | 按科研、设计、代码、测试等角色反馈 | GitHub Issue（提交时才需要账号） |
| [支持项目](support.html) | 了解维护方式和资金原则 | 社区、路线图 |
| [开发者](developers.html) | 查看源码、Figure Grammar 和可复现脚本 | GitHub 仓库 |

站内搜索在所有页面右上角。搜索“CE”“拼图”“安装”等词，先显示能开始做的入口，再显示样图、学习资料和开发者资料。网站没有文件上传或 API Key 表单。

新手主路径：**首页 → 开始使用 → 选软件 → 选系统（WorkBuddy 跳过）→ 下载与安装 → 用演示数据试一张图**。
