第一次用

跟着做，先画出一张。

选择你使用的软件，下载演示文件，再把页面给你的任务句交给它。遇到不会的步骤，旁边就有说明。

带我开始
  1. 选软件先选你现在用的 Agent
  2. 安装只看适合当前软件的步骤
  3. 试一张用附带的演示数据验证

放心使用

你的数据，始终由你决定怎么用。

本站不接收实验文件，也不索取 API Key。绘图脚本不会加项目水印；原始数据保持不变。在线 Agent 的文件处理方式，请以你所用软件的设置为准。
