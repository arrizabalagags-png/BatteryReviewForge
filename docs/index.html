先看看电脑上有没有能运行技能的 AI 软件。页面会根据你的答案，带你找到下一步。

带我开始
  1. 看看软件装过、没装过、不确定都能选
  2. 安装技能只看适合当前软件的步骤
  3. 试一张用附带的演示数据验证

放心使用

你的数据，始终由你决定怎么用。

本站不接收实验文件，也不索取 API Key。绘图脚本不会加项目水印；原始数据保持不变。在线 AI 软件的文件处理方式，请以你所用软件的设置为准。
