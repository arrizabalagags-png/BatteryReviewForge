## EIS 科学与显示

CPE / Warburg 模型为 `Rs + (CPE || (Rct + W))`，`W=σ(1−j)/√ω`、`Y_CPE=Q(jω)^α`。86 个原始频率点全部保留。理想 RC 模型为 `Rs + Rct/(1+jωRctC)`，120 个频率点全部保留。

三个视图逐行读取同一 CSV 的 `Re Z` 与 `Im Z`；模值为 `abs(Z)`，相位为 `arg(Z)`，没有另编 Bode 数据。Nyquist 显示 `−Im Z`，横纵方向的每 Ω 使用相同像素长度；相位保留真实负号。两图均为白底、四边框、实线、无点，没有平滑、插值或改 CSV。[Gamry 官方 EIS 说明](https://www.gamry.com/application-notes/EIS/basics-of-electrochemical-impedance-spectroscopy/)说明这些复阻抗表示和电路元件约定。

这些电路假定小信号、线性、稳态与被动元件；Warburg 另假定半无限扩散边界。没有拟合真实电池、推断扩散系数或验证实际反应机理。
