# BatteryReviewForge 的方向

**少花时间调图、拼图和反复核对格式，把时间还给科研思考。**

这是面向电池科研人员的开放工具。它把领域知识、数据检查、绘图、拼版和证据核查接成一条可追溯的工作流。研究者可以直接说“我有循环数据”“我有六张图”“我要画机制图”“我要整理一篇综述”，工具负责选择合适入口，并告诉作者还缺哪些关键条件。

## 先把三件事做扎实

1. **数据 → 图。** 读取常见表格，核对电芯构型、测试协议、单位和容量分母，再画出可编辑的图并保留来源记录。
2. **已有面板 → 整图。** 按论文最终尺寸安排阅读顺序、主次、边距、面板字母和实际绘图区，输出逐面板检查结果。
3. **文献与课题 → 图件策略。** 从已核实的论文和图注中学习常见证据链，建议每张图回答的问题、所需证据及不能越过的推断边界。

库伦效率、全电池、半电池、对称电池、电解液机理等电池特有条件，是这三项能力的共同基础。两个测试协议不同的结果，不因为画在同一坐标系里就变得可直接比较。漂亮的图也不能替代可靠数据、方法和来源。

## 面向所有人开放

- **看得懂：** 用人话选任务，参数缺失时说明缺什么，不凭文件名猜实验条件。
- **改得动：** 保留原始文件、配置、导出的 SVG/PDF 和来源记录，允许作者追查每条线怎么来。
- **用得起：** 核心代码、说明和原创模板开放，先服务研究者与课题组的日常需要。
- **守边界：** 未公开实验数据、下载的论文和版权不明的素材不进入公共仓库；示例图明确标成虚构数据。
- **能共建：** 在核心路线可靠后，逐步接受钠电、锌电、固态、锂硫等领域的经过核查的贡献。

“一次出图”是减少重复试错的目标，不是跳过科研核实的承诺。真正可用的成果要经得起数据、条件、图注、最终尺寸和复用权利的检查。

**English in one sentence:** An open, battery-aware workflow for turning data, existing panels, and literature evidence into traceable scientific figures while leaving more time for scientific thinking.
