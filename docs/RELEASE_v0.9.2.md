# 电研搭子 · VoltPeer v0.9.2

本版帮助多步任务在中断、换模型或上下文压缩后可靠地接着做。15 个技能的技术 ID 和已建立的科学要求保持兼容。

## 技能更新

- 所有技能加入简短的执行入口，以及按需读取的执行与恢复指南。
- 按可用工具、看图能力和一次小任务的实际表现选择引导、自主规划或审查模式。模型价格不作为能力证明。
- 多步工作保存 `TASK_STATE.json`：输入路径和哈希、已确认条件、用户选择、结果、检查记录、待确认问题和下一步。
- 恢复时重新核对文件。输入变化、作者编辑过输出、文件丢失或检查未完成时，不沿用旧的完成结论。
- 每个独立技能包都包含状态模板和只读检查器，WorkBuddy 单技能导入也能使用。
- 自主规划仍需遵守测试协议、来源、单位、保持率参考圈和真实数据要求。看图或执行工具不可用时，说明哪些检查尚未完成。

## 验证与范围

状态检查覆盖文件变化、输出缺失、待确认问题、检查证据与独立包一致性。检查器验证记录结构和文件，不会替代科学判断或自动完成视觉审查。未声称所有宿主或所有内置模型都已完成真实任务测试。

已有版本更新前，保留自己修改过的规则和配色；使用安装器已有的同名保护与备份流程。
