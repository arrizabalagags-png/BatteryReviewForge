# v0.8.2 网站与拼图验收

核对日期：2026-09-24。这里记录已实测的结果，也说明哪些情况仍需要作者检查。

## 网站

- 本地浏览器按 320、390、768、1024、1440 CSS px 宽度检查：首页无横向溢出，标题在窄屏保持完整，主要按钮和正文未相撞。
- 320 和 390 px 手机宽度检查菜单、搜索与上手入口。菜单展开状态有提示；搜索可用中文“库伦效率”和英文“CE”，按 Esc 后焦点回到搜索按钮。
- 上手页从软件选择进入安装步骤。Codex 与 WorkBuddy 下载链接均指向 v0.8.2；页面脚本从当前版本号生成链接，避免浏览器缓存旧下载路径。
- 首页保留一张完整科学样图；图可打开 SVG 放大。页面不暗示在网站上传数据，演示图紧邻“虚构数据”说明。
- 文字与背景的实测对比度：正文与白底约 16.8:1，次级文字与白底约 7.6:1，操作蓝与白底约 6.3:1。

## 绘图与拼版

- 七张项目样图重新生成，并随图保存 `alignment.json`。每张定量多面板图在最终物理尺寸上计算绘图区的上下、左右边界。
- 六张独立图片拼成的[示范组合图](assets/showcase/assembly-example.png)附带[原图、排版文件和检查报告](assets/showcase/assembly-demo.zip)。严格模式做了 27 项毫米尺检查，最大绘图区偏差约 0.0022 mm；检查报告保留原始数值。
- 拼图技能要求先声明哪些面板需要对齐，并提供可核实的绘图区位置。相同行按上边界、下边界、高度检查；相同列按左边界、右边界、宽度检查。超过 1.5 pt 或缺少可测位置时，严格模式停止导出；红框表示画布槽位、蓝框表示放入的图、青框表示可见内容、绿框表示绘图区。
- EIS 示范图的绘图区为了保持等比例，已按最终渲染坐标与相邻面板重新对齐。科学曲线、坐标和单位由脚本与数据生成；没有用装饰性 AI 小图替代实验图。

## 仍需人工确认

- 作者上传的任意截图可能没有独立的坐标轴和可读尺寸。此时不能声称绘图区已对齐；需要原始 SVG/PDF、可编辑绘图文件，或作者在检查图上确认边界。
- 期刊规定的最终字号、字体嵌入、图注、色盲可读性与科学解释仍需按目标期刊和原始数据复核。
- 所有网站示范曲线均是标明来源的虚构数据，只用于试用和展示，不可作为实验结果。
- 手机缩略图可用于选择样图；阅读刻度和细节时应打开 SVG 放大。
