# VoltPeer 0.11.0 Beta — naming candidate

Local candidate prepared on 2026-10-02. All active Skill IDs use the VoltPeer namespace. Six main products are plotting, Figure assembly, data import/preparation, writing, argument/outline planning and polishing; nine supporting research workflows remain available.

See [the exact map and safe migration](NAMING_MIGRATION.md). Legacy installations are detected; migration is explicit and old trees/customisations are backed up outside discovery. No duplicate alias Skills are installed and conflicting old/new installations are refused.

Scientific examples, original data and historical published packages remain unchanged. The new maintained Starter adapter uses one canonical plot Skill and the same scientific runtime. Native parser code is preserved. Research-paper input/evidence/section and argument contracts were added separately from the naming migration. Full model/host behavioural validation remains NOT_RUN.

The polishing Skill carries the 10 public original language-guide files (525,484 bytes) based on the separately frozen 100-paper corpus. The initial corpus engineering audit recorded the original 525,075-byte snapshot. The 0.11.0 integration separately revises only `evaluation_cases.json`: BP10 accepts the source's weaker “is consistent with” wording, and BP22 accepts an equivalent explicit negative translation. All original case inputs and deliberate corrupted outputs, the 100 DOI records and the other nine guide files remain unchanged. Source scope and DOI metadata are preserved inside the guide. The guide does not contain copied journal full texts and its integration does not certify a model's writing quality.

- 26 isolated installer transactions passed on PowerShell and Git Bash, including legacy detection, explicit migration, byte-preserving backups, conflicting old/new trees, missing-map refusal, CRLF maps and two actual Windows junction refusals. Two file-symlink cases were skipped because the host did not grant that privilege.
- All 15 canonical source Skills passed structural, local-reference and dependency-declaration checks. Portable Skill, data preparation, reference sync and Starter protection tests retain their separate recorded scopes.
- 34 new ZIPs carry 63 isolated Skill copies with complete contracts, references and assets; 3 preserved recipe ZIPs and 30 historical demo metadata sets were checked separately. See the external [current distribution record](validation/2026-10-02-naming-distribution-v0.11.0.json).
- 1,159 fixed historical public files, including 194 existing ZIPs, remained byte-identical to the pre-migration inventory. The native parser and instrument importer remain unchanged.
