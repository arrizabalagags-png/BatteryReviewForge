使用说明

安心使用，也知道每张图从哪里来。

我们希望你先把工具用起来。下面把演示样图、论文使用和素材来源的边界集中说清；需要时再回来查。

关于网站样图

网站上的曲线、ToF-SIMS 色斑和数值均由公开绘图代码生成，全部是虚构演示数据，不是实验结果。几何示意图是原创概念图，不代表某个材料已经被证实具有图中的结构。对应代码、CSV 和可编辑文件随仓库公开。

关于论文使用

工具能排版、绘图和提醒你检查，却无法替你验证实验、判断因果或决定文献是否支持结论。发表前请用原始数据核对数值、单位、测试条件、图注和引用；不同电芯或测试协议不能只因配色相同就直接比较。

关于素材和授权

公开资源库只收录本项目原创的代码与示意元素。你上传的论文、商业素材、照片和仪器图仍受原来的权利约束；重新配色或拼版不会自动取得转载许可。使用他人图件时，请按来源与目标期刊要求确认许可和署名。

关于软件与密钥

这是一个静态介绍网站，不收集数据或 API Key。请在你所用 Agent 的官方设置中登录或配置模型。各平台的技能导入能力不同；适配状态见项目的兼容性说明。

关于 AI 辅助披露

若目标期刊要求说明 AI 辅助写作或绘图，请按投稿时的官方政策披露。让图更自然不等于可以省略应有的说明。

关于开源许可

项目按 MIT License 发布，允许在许可条件内使用、修改与分享，软件按原样提供。论文数据、第三方图片和作者自己的研究结论不因本项目许可而自动转为 MIT 授权。
