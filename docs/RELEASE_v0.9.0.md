# BatteryReviewForge v0.9.0

电研搭子 · VoltPeer 的开源技能包。仓库名、技能名与安装命令继续使用 BatteryReviewForge，兼容已有项目。

- 15 个技能，覆盖数据准备、绘图、拼图、实验规划、综述写作、查证和返修。
- 完整安装包、WorkBuddy 完整合集、WorkBuddy 绘图与拼图入门套装。
- 保留真实协议区分、数据来源记录、最终物理尺寸和绘图区对齐检查。
- 网页上手指南、可下载的虚构演示样例与中英文使用说明。

这是已经随网站分发的 v0.9.0 安装包的正式 GitHub Release；此次补齐发布记录，不改写实验数据或重新生成包内示例。

## Verification limits

Distribution structure, version consistency and archive integrity are checked automatically. Client-specific installation through first SVG generation still needs verification on each supported app and operating system. Synthetic examples are demonstrations, not experimental results.

Website authoring source is maintained separately and is not included in these open-source skill archives. Figures and research data supplied by users remain their own.
