# Figure Director：先决定读者看什么，再决定格子怎么排

这份规则用于 **3 张以上、证据角色不同** 的电池论文组合图。两张同类曲线的直接比较，仍可用等宽版式。它是构图判断，不会替代原始数据、图注、期刊规范或作者对科学结论的确认。

## 开工前的一张小卡片

用作者材料填写，不知道就写“待确认”，不要补猜：

| 问题 | 最短回答 |
| --- | --- |
| 整张图想回答什么？ | 一句可被现有证据支持的话；不能只写“展示结果” |
| 每张图在做什么？ | `CONCEPT` 体系/设计，`OBSERVATION` 直接观察，`MECHANISM` 条件化解释，`VALIDATION` 独立验证，`PERFORMANCE` 电池表现，`BOUNDARY` 适用边界，`SUPPORT` 辅证 |
| 第一眼看哪里？ | 选 0–2 个主角，说明它们为何值得更大面积；直接比较的同类图应保持等大绘图区 |
| 然后看到哪里？ | 用“设计 → 观察 → 验证 → 性能”之类的实际证据路径写出顺序；证据不完整时不要画成完整因果链 |
| 哪些可减？ | 信息重复的面板可移至 SI、合并或取消；记录理由，不偷偷删除作者要求保留的证据 |
| 最后停在哪里？ | 重要性能或边界结论可以成为视觉终点；若核心不是性能，就让最关键证据收束 |

**给新手的第一句：**“我先看看你给的图，不急着拼。我会告诉你哪张最重要、哪几张放在一起，以及有没有需要重新导出的图。”随后用“我看到了 / 我能做 / 还缺什么 / 我建议的下一步”四行回应；只问会改变科学意思的缺口。

## 三个候选，供作者一眼选

对复杂图先出三张低成本线框小预览或简明布局说明，不必把三个全渲染到投稿质量：

1. **经典整齐：**稳妥、便于同类条件比较。需要同行对照时保持绘图区相等。
2. **证据故事：**先引入体系，再把相近证据成组，最后呈现验证或性能。作为默认推荐，附一句为什么。
3. **重点突出：**只在核心证据足够强、目标尺寸仍可读时，给主面板更大面积；不是为了制造视觉冲击而夸大弱证据。

每个方案标出面板字母、角色、阅读顺序、预计毫米尺寸和任何牺牲（例如小图字号风险）。若只有两张同类图或作者给了固定版式，不强行生成三案。选定后再写 manifest。作者若未选且已授权你决定，可采用证据故事方案并记录理由。

## 五个编辑动作

- **主次：**面积反映证据功能。不是六图平均，也不是把最漂亮的图自动放大。
- **分组：**Raman/RDF 等分子证据靠近；CE、Li∥Li 和全电池可形成验证组，但不能凭摆放暗示不同条件直接可比。
- **节奏：**不同行可有不同高度；同类比较面板的真实绘图区必须一致。留白用来分隔逻辑阶段，而非填满每一处。
- **连续：**同一样品跨图同色，轴基线、字母、图例语法相同；颜色若来自原始成像强度，不为统一色卡而改。
- **收束：**主图的阅读位置要自然，但不把“性能更好”当作未经条件审计的结论。

例如体系示意、Raman、RDF、CE、Li∥Li、全电池六张素材，可考虑概念通栏 → Raman/RDF 并组 → CE/Li∥Li 并组 → 全电池通栏。这个顺序只是候选；若全电池条件不支持该论点，应重写主张或改为边界面板。面板字母是定位符；不要给每个 panel 再加一句装饰性副标题。条件、方法和论证写进图注。

## 拼不齐时的重绘闭环

库存检查若发现某 panel 字太小、画布比例不合、图例外置或空白太大，先判断能否从原始数据或可编辑文件重出目标尺寸。把目标槽位的毫米尺寸、坐标范围、必要标签、线型及相同样品颜色交给 `battery-review-figure`，生成新 panel；记录源文件和修改，然后回来重新拼版和检查。不要凭图片描出新曲线，不能以 AI 生成显微纹理代替实测图。只有原始数据不可得时，保留原图或说明无法达到同等质量，不能假装已重绘。

## 交付前的双层检查

**论文图检查：**数值、单位、比例尺、条件、来源/权限、最终尺寸、坐标和图例均合格；报告每个未解决项。**展示样图检查：**在论文检查之外，还要让没有背景知识的人看出主次、顺序和收束；检查疏密、留白、视觉重量和有无重复面板。展示用虚构数据必须在图片旁和元数据中明示，不能包装为实测结果。第一版是供作者选择与修改的预览，不承诺一次通过投稿。

## English

For heterogeneous multi-panel figures, state one supported claim, assign evidence roles, choose at most two visual anchors, and sketch the reading path before choosing a grid. Offer compact conservative, narrative, and emphasis layouts when the decision is nontrivial. If an existing panel cannot remain legible at target size, regenerate it from owned raw data or editable source and reassemble; never trace values from a picture. Apply both scientific production checks and editorial hierarchy checks.
