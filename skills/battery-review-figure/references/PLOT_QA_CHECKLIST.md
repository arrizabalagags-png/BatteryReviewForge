# 出图前后检查

需要具体演示配方时看 [SHOWCASE_SPEC.md](SHOWCASE_SPEC.md)；图型证据等级见 [BATTERY_FIGURE_GRAMMAR.md](BATTERY_FIGURE_GRAMMAR.md)。这张表用于实际交付时逐项检查，不是自动“投稿合格”证书。

## 输入与科学

- [ ] 读原表或仪器导出，列名、单位、方向、圈数、时间、样本 ID 可对应；不依据文件名猜电芯。
- [ ] 记录电芯、正负极、容量分母、倍率/电流、载量、电压窗、温度、形成圈和已知的 N/P、E/C。未知字段显式列出，不补数。
- [ ] 逐圈 Li∥Cu CE 和 Aurbach 协议分开；保持率只有给出参考圈才计算。
- [ ] 拟合、平滑、扣背景、归一化、裁点、导数和插值有参数与原始文件；异常与失效段保留。
- [ ] 跨样本和跨文献的点有来源 ID、共同指标分母与可比条件；`NR`、`NV`、`NA` 不混。
- [ ] 多 panel 的源数据、样本、颜色和所选圈数一致。仅因版面空白而补 panel 属于失败。

## 版式与导出

- [ ] 以目标最终毫米宽高检查轴名/单位、刻度、字母、图例、颜色及标尺，不在屏幕大图上臆测字号。
- [ ] 比较性 panel 的**真实绘图区**有毫米尺；同组上/下/宽度差 ≤1.5 pt。只对齐图片外框不足以通过。
- [ ] 热图有色标及色标范围；EIS 复阻抗坐标未被拉伸；显微/离子图有实际校准与归一化说明。
- [ ] 无无意义副标题、背景网格、图内产品标识、彩色终点数字或重复的“500 cycles”字样。
- [ ] 导出 SVG、PDF 和预览 PNG；核对 SVG 是否包含栅格面板，检查 PDF 实际嵌入字体与特殊字符。
- [ ] 在最终尺寸放大与缩小各看一次，确认标签不遮曲线、colorbar 可读、裁边完整，移动端网页另用适合手机的示例。

## 公开展示

- [ ] 合成数据在近图和 `metadata.json` 均标 `synthetic_demo`，不是实测、不是来源引文。
- [ ] CSV、生成脚本、图件、变量/单位/条件和 QA 文件成套可下载，链接可打开。
- [ ] 第三方图像的复用许可单独核验；原创重绘只用原理与经核对的信息，不拷贝原图像素。
- [ ] 作者或领域复核者最终检查实际实验解释；机器检查只报告它真正检查过的范围。
