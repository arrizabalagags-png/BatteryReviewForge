# Four optional electrochemistry displays

These are **optional variants**, not default paper templates. The linked primary studies support the kind of measurement shown, not the synthetic values, curve shapes or exact two-panel layout. The examples contain no copied paper data. Supply author-owned CSV and explicit metadata before use.

Run from the figure skill directory with `python scripts/render_specialist.py --recipe NAME --input-folder INPUT --output-dir NEW_OUTPUT --style forge`. Each folder has `data.csv` and `metadata.json`; the output directory must not yet exist. Metadata requires `figure_grammar_id: "optional:NAME"`, `source_files: ["data.csv"]`, `test_conditions`, `render_options`, and `reference.default_template: false`. Outputs are PNG, SVG, PDF, and provenance JSON with post-draw millimetre alignment.

| Recipe / source | `data.csv` fields | Required `render_options` | Boundary |
|---|---|---|---|
| `aurbach_protocol` · [Li et al., *Nature Communications* 2025, Fig. 4b and Methods](https://doi.org/10.1038/s41467-025-66197-7) | `stage,time_h,voltage_V,current_density_mA_cm2` | `protocol_name`, `cell_configuration`, `current_sign_convention`, `capacity_schedule_mAh_cm2`, `cutoff_description`, ordered `stage_sequence` | Plots each supplied stage's voltage and current on the same time basis. Does **not** infer reservoir amount, CE formula, average CE, or whether a claimed protocol exactly matches the cited one. Authors must provide stage identity and signed-current meaning. |
| `eis_frequency` · [Chen et al., *Nature Communications* 2022, Fig. 2e](https://doi.org/10.1038/s41467-022-29596-8); [BioLogic EIS plot note](https://www.biologic.net/documents/eis-plot-electrochemistry-battery-application-note-8/) | `sample,frequency_Hz,z_real_ohm,z_imag_ohm` | `cell_configuration`, `measurement_state`, numeric `temperature_C`, positive `perturbation_mV`, `frequency_direction` (`ascending` or `descending`) | Plots Z′ and −Z″ against log frequency from the **signed** imaginary input. It does not fit an equivalent circuit, assign semicircles or estimate resistance. Existing `eis` showcase remains a separate Nyquist/phase model demo. |
| `chronoamperometry` · [*Nature Communications* 2022, Fig. 2a](https://doi.org/10.1038/s41467-022-32139-w) | `sample,time_s,current_density_mA_cm2` | `cell_configuration`, `reference_electrode`, `current_sign_convention`, numeric `applied_potential_V`, `zoom_time_s: [lo,hi]` | Full current transient and same-data early-time zoom. A visible peak or decay is not a fitted nucleation rate, mechanism, plated charge or stability metric. |
| `ocv_rest` · [*Nature Communications* 2022, Fig. 1a,b](https://doi.org/10.1038/s41467-022-29837-w) | `sample,time_h,voltage_V` | `cell_configuration`, `initial_state`, `rest_condition`, numeric `temperature_C`, `zoom_time_h: [lo,hi]` | Full and early open-circuit voltage relaxation. A voltage drop is **not** a capacity-loss/self-discharge measurement. That requires an appropriate recovered-capacity experiment and protocol. |

The example metadata files show complete synthetic contracts. Do not copy their numerical settings into an experimental project. Preserve acquisition order and original CSV; duplicate, missing, nonfinite or out-of-range inputs require author review. Scientific claims and final-size journal requirements still need human checks.
