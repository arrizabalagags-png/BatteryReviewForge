# 把科研图做得像认真编辑过，而不是套模板

“去 AI 感”指减少空洞的装饰、重复的模板痕迹和未经核查的视觉细节。它**不**意味着隐藏工具使用、故意加瑕疵，或把生成图伪装成真实实验。最终图应让读者先看懂研究问题，再看清数据和证据。

## 开始前先写三句话

1. **这张图回答什么？** 用一句能被证据支持的话说清主问题。
2. **读者先看哪里？** 指定一个主面板或主曲线；其余面板各负责一种不同证据。
3. **哪些不能画成事实？** 列出缺失条件、推测的机理、示意比例、未校准的影像和版权边界。

如果这三句写不出来，先改图件结构，暂时不要调配色。

## 一轮“减法编辑”

| 看上去很像自动模板的做法 | 改成什么 |
| --- | --- |
| 每个面板同样大、同样抢眼 | 让关键证据占主要面积，辅助证据退后；同类比较面板仍保持相同绘图区 |
| 大面积渐变、发光、阴影、圆角卡片、泛用图标 | 白色或真实成像背景；少量结构线和留白。装饰只有帮助分组或解释时才保留 |
| 虹色、每张图换一套颜色 | 一个中性色系、一个主信号色，必要时加一个警示色；同一电解液/电芯跨面板保持同色 |
| 图里重复写满结论、箭头和花哨标签 | 图上保留读图必需的对象名、轴、单位和少量关键标注；方法、限制、统计放图注 |
| 漂亮但无来源的分子、晶体、SEI 层、显微纹理 | 依据作者结构/原始数据重画；假说、计算、实测与纯示意分别标识 |
| 把不同实验曲线调成同一“顺滑”形状 | 保留原始点、异常和失效区段；任何平滑、归一化或删点都记录方法和前后数量 |
| 在图里加巨大“DEMO”横幅、品牌抬头、解释副标题和页脚 | 论文图只留分图字母及读图必需标注；网页样图旁清楚写“虚构演示数据”，下载包和元数据也标明，不用图内脚注占画面 |

这些是编辑判断，不是机械禁令。例如影像底板可以是黑色，确有意义的分区也可以用浅色块。删除装饰后，读者仍应知道每个符号、线条和颜色代表什么。

## 电池图的具体做法

- **CE、全/半电池、对称电池：**先核对电芯、单位、CE 定义、容量分母、协议与测试窗口，再定轴。主曲线保留失败、波动和全时程；inset 必须有清楚的截取范围，不盖住主数据。
- **EIS、谱学、结构计算：**先说明测试/计算状态。不要把外观相似的半圆、峰或色斑直接写成同一机制；同类色标和峰归属要一致。
- **SEM/TEM/AFM：**保留原文件，比例尺用校准信息生成；对照组的裁切、显示尺寸和处理记录可追查。不要用生成纹理冒充显微图。
- **多面板：**按“设计依据 → 直接观察 → 条件化解释 → 电池验证”组织时，必须允许证据缺口打断这条链。拼版时对齐实际绘图区、共享基线与面板字母，而不是只对齐图片外框。
- **示意图：**用几何、箭头和明确的证据标签解释关系。没有物理模型时不要画出貌似精确的层厚、颗粒尺寸或 3D 结构。

## 最终尺寸下的验收

1. 在目标栏宽看 **PDF/SVG 原版** 和 300 dpi 预览。轴标题、刻度、图例、比例尺和面板字母均可读；本库默认检查值见 [图型小抄](BATTERY_FIGURE_ATLAS.md)，目标期刊要求优先。
2. 同类面板的绘图区、轴向、单位、图例顺序和颜色身份一致。逐个检查文字碰撞、曲线遮挡、裁边、空白是否失衡。大屏上好看不代表缩到单栏后能用。
3. 黑白打印和色觉差异下，仍能用线型、符号或直接标签识别系列。真正的影像、光谱和数值不能为了统一色卡而重着色。
4. 交付原始数据/源图引用、可编辑 PDF/SVG、预览图、图注和来源记录。未通过科学、可读性或使用权检查的图标成草稿，别称“可直接投稿”。

**复查问题：**拿掉配色、阴影和大标题后，这张图还清楚吗？陌生的电池研究者能不猜测地读出单位、电芯与比较边界吗？每个看起来“很真实”的结构细节能追到来源吗？如果有一个答案是否定的，就再编辑一轮。

## 关于 AI 辅助和期刊政策

模型可以帮忙规划版式、写代码和提出候选示意，但定量图必须由可追溯数据和可复现方法生成；模型生成的显微、谱学或实验图像不能代替观察。保留工具、版本、源文件与人工修改记录。目标期刊对 AI 辅助图件的允许范围和披露要求可能变化，投稿前查该期刊**当期官方政策**，按要求说明；视觉上的“自然”不是免披露理由。

参考的公开编辑原则：[Nature Research figure guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/) 强调坐标、单位、可读文字、可编辑元素和去掉多余装饰；[Nature Reviews Physics 编辑说明](https://www.nature.com/articles/s42254-019-0094-7) 强调一组图内的字体、颜色、标签一致和删除无关信息；[PLOS Biology 的图像可读性研究](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.3001161) 记录比例尺、inset、颜色与标注的常见问题。[Springer Nature](https://www.springernature.com/gp/policies/editorial-policies/ai-manuscript-preparation) 与 [Elsevier](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals) 的 AI 图件政策说明，投稿时还须按具体刊物核实适用条款。
