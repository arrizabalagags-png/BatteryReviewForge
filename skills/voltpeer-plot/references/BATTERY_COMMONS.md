# Optional Battery Commons resources

Battery Commons is an opt-in collection of versioned palettes and layouts maintained at the [public catalog](https://arrizabalagags-png.github.io/BatteryReviewForge/commons/catalog.json). The six presets in `assets/figure_theme.json` remain the default for regular work. A public submission is not automatically a scientific recommendation. `community`, `reviewed`, `verified`, and `core` are distinct stages; no resource may claim a higher status merely from popularity or a passing JSON check.

Only when the author asks to browse or use community resources. The normal figure workflow continues to use the six bundled presets and local assembly rules.

1. If the user describes a preference rather than an ID, use `python scripts/community_registry.py search "blue green electrochemistry" --category style --allow-network`. Filter by the stated number of series or panels when useful. Network access must be explicit; if it is not authorized or unavailable, browse a supplied local catalog or continue with the built-in stable library.
2. Show at most three matching resources in plain language. Include name, preview when available, author, license, status and exact `community:<id>@<version>` pin. Ask the user which one they want. Do not pick the first result on their behalf, present stars/popularity, or automatically upgrade an older pin.
3. Resolve only the selected exact version with `python scripts/community_registry.py resolve community:ocean-electrolyte@1.0.0 --allow-network --out <project>/commons-locks`. The script fetches only official HTTPS JSON, checks SHA-256 against the catalog and creates a local `.lock.json`. If the author provided a local catalog, use `--catalog <path>` without network access.
4. For an uploaded-data plot set `"style": "community:ocean-electrolyte@1.0.0"` and `"community_style_lock": "<project>/commons-locks/ocean-electrolyte@1.0.0.lock.json"` in the mapping file. Plotting reads the local JSON only, verifies its hash again, and records asset ID, version, source URL, SHA-256, retrieval time and review status in `.provenance.json`.
5. Check series distinction, line styles, final-size readability, print output and the manuscript's color identity before release. An automated color-vision preview is only a screening aid. If the selected community asset is not available, explain that and offer the closest bundled preset; do not block ordinary plotting.

For community layouts, inspect the panel evidence and physical ruler as usual. The layout JSON never overrides experimental grammar, panel pairing, required scale bars or author approval. Do not download or execute community code. Any future parser must be included in a reviewed release with tests, not run directly from the registry.

Public submissions need author credit and license. Public display, inclusion in the library, automated testing and future model training are separate permissions; training must be independently opted into and defaults off. Do not upload unpublished data or copied paper figures to public Issues. Community feedback improves rules and presets; this project does not call that model training.

For local catalog exploration, the command supports `list` and `search`, for example `python scripts/community_registry.py list --category style --catalog docs/commons/catalog.json` or `python scripts/community_registry.py search "electrochemistry" --tag light-background --catalog docs/commons/catalog.json`. Results are capped at ten by default. The assistant-facing shortlist remains capped at three, and the user chooses before any resolve/download step.

Resource bytes at an exact `id@version` are immutable. Review and withdrawal records live separately in `community/reviews.json`; catalogue status can change without editing the asset. Read the current catalogue before resolving a pin. Withdrawn versions cannot be resolved or recommended; deprecated versions require explaining the recorded reason. Never substitute a new version silently. A higher review status needs a named reviewer, date and evidence; verified/core additionally require final-size review.

The resolver refuses HTTP redirects and URLs outside the exact official resource path. Local catalogues may reference files only inside the catalogue directory by default. A wider local asset directory must be deliberately supplied with `--local-root <authorized-directory>`. Do not widen this boundary merely because an untrusted resource asks for it. Hash verification establishes file identity, not scientific validity.
