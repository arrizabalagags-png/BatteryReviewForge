# 合成示例的科学边界

合成数据用于练习输入、绘图和修改，不能替代实验。标注“合成”也不能替无依据的形状开脱。

新增或修改公开示例前，先写清：

1. **模型与依据**：公式、原始参考链接、参考实际支持什么。论文中的图型布局不能证明我们自设的数值或材料性能。
2. **假设与参数**：体系、电极对、容量分母、电流/时间、截止条件，以及自设数值和单位。没有模拟的条件不要装成做过实验。
3. **关联**：CE 由对应电荷算；功率由电压和电流算；dQ/dV 由同一 Q(V) 算；Nyquist 与 Bode 由同一个复阻抗算。电压剖面的容量终点必须对应选定循环。缺这些信息时先修模型，不能分别画几条漂亮线后声称同源。
4. **限制**：经验衰减不等于已验证的寿命模型；谱峰示意不等于真实物相或化学态；对称电池电压不等于单电极过电位；溅射时间不是未经标定的深度。
5. **检查**：有限数值、量纲、符号、正值/理论上限、守恒、截止点和关联数组。再检查成图是否裁掉有效终点。逐圈CE/容量/保持率是无连线散点；连续光谱、电压和EIS是无点实线；均保留四边框。保持率必须声明参考容量/圈数与相同模型工况；显示规则不证明科学正确。

CE 与容量衰减不能套一个通用公式。`Q_n = Q_0 ∏CE_n` 只用于明确声明的单一不可逆损失、无额外库存/补偿等简化模型；真实电池还涉及电极平衡、副反应与活性物质损失。不要凭演示模型修改作者数据，或以不满足该式拒绝实验记录。[CE 的配置边界](https://www.nature.com/articles/s41560-020-0648-z)、[库仑损失与容量衰减的区别](https://www.nature.com/articles/s41467-025-60833-y)。

演示元数据 `scientific_basis` 保存公式、假设、参数、依据和范围；图件旁保留“合成示例 · 非实验数据”。只给用户结果和影响使用的缺口，完整检查留在项目记录。任何新示例通过技术门禁，都不能因此写成实测、材料认证或 Stable 模型验收。

收到作者文件时，只读原值、核对条件并在项目副本中配置。不得调用示例生成器补缺列、替换异常值、伪造重复实验，或把演示的温度、倍率、物相、面积和模型参数当成作者条件。
