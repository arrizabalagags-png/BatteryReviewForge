GitHub Issues 公开可见。请提供软件/包版本、期望结果、实际问题及可分享的最小合成例子；不要附未公开数据、API key、完整私人日志或账号路径。

| 问题 | 已有入口 |
| --- | --- |
| 解析、绘图、导出或安装程序错误 | [代码问题](https://github.com/arrizabalagags-png/Voltpeer-skills/issues/new?template=python-code.yml) |
| 单位、科学条件、性能指标或引用规则 | [电池科学问题](https://github.com/arrizabalagags-png/Voltpeer-skills/issues/new?template=battery-science.yml)；附 DOI / 官方说明与核查位置 |
| 教程与翻译不清楚 | [文档建议](https://github.com/arrizabalagags-png/Voltpeer-skills/issues/new?template=documentation.yml) |
| 新需求、使用场景或原创工具 | [需求与共建](https://github.com/arrizabalagags-png/Voltpeer-skills/issues/new?template=outreach.yml) |
| 安全漏洞或泄露风险 | 先读 [安全报告方式](SECURITY.md) |

科研方法讨论以可核查的规则、共享问题和明确适用范围为主。维护者不承诺逐项咨询、替作者认证实验真实性或代为获取无权访问的论文。模型账户、额度与该软件自身故障请联系对应提供方。

Contributions use [CONTRIBUTING.md](CONTRIBUTING.md). The existing Issue forms cover code, science, documentation and user needs. Include a version, expected versus observed behavior and a small shareable example; keep private data and credentials out of public Issues. Method discussions need traceable sources and a defined scope. The maintainers do not promise individual research consulting, experimental certification or access to restricted publications. For security concerns, follow [SECURITY.md](SECURITY.md) before sharing details.
